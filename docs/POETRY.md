# Работа с Poetry
Информацию о дополнительных параметрах, о которых тут написано, смотреть [тут](https://habr.com/ru/articles/593529/?ysclid=mjt8xv7dac693714920)

## Добавление библиотеки
Можно указывать версию пакета. Принимает дополнительные параметры

```bash
  poetry add package_name
```

## Удаление библиотеки
Принимает дополнительные параметры

```bash
  poetry remove package_name
```

## Установка при помощи pip:

```bash
  pip install poetry
```

## Первичная установка пакетов
Установка библиотек в новый проект из poetry.lock

```bash
  poetry install
```

## Обновление пакетов
Есть возможность обновить только определенные пакеты. Метод принимает дополнительные параметры

```bash
  poetry update
```

## Просмотр зависимостей
Будет показана структура всех пакетов с их зависимостями

```bash
  poetry show --tree
```

## Создание нового проекта 
Создание папки с введенным названием проекта, где будет pyproject.toml

```bash
  poetry new new_project
```

## Инициализация
Сделать poetry пакетным менеджером в уже имеющимся проекте

```bash
  poetry init
```
